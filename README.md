# Journeys - Tabletop Simulator playtest mod

A plug-and-play Tabletop Simulator mod for playtesting **Journeys**, a co-op legacy card game.

## Layout
- `cards/` - the exported card images (the source for everything else).
- `data/journeys-cards.xlsx` - the card catalog: cards, sets, classes, adventures, journey map, bosses. This is the source of truth.
- `tts/build/` - the build: `catalog.py` (card data) and `build.py` (makes the deck sheets, images, `data.lua` and the save).
- `tts/src/global.lua` - the mod's script (hand-written). `tts/src/data.lua` is generated by the build, so don't edit it.
- `tts/sheets/`, `tts/images/` - generated images. TTS loads them from this repository.
- `tts/Journeys.json` - the TTS save ("Journeys - Playtest"). Copy it to `Documents/My Games/Tabletop Simulator/Saves`.
- `tts/README.md` - how to play with the mod.

## Building
```
python3 tts/build/build.py <repo folder> https://raw.githubusercontent.com/galvanicchoir/journeys-tts/main
```
Every image link gets `?v=<content hash>`, so a changed image always gets a new link and TTS never shows a stale cached copy.
