# Journeys - Tabletop Simulator playtest mod

A plug-and-play Tabletop Simulator mod for playtesting **Journeys**, a co-op legacy card game.

## Layout
- `cards/` - the exported card images (the source for everything else).
- `cards/framed/` - encounter cards drawn in the new frame by `tts/build/render_cards.py`. The build uses one of these in place of the export whenever it exists.
- `art/encounters/` - card art for the new frame, one file per card name (`Goblin Horde.png`).
- `data/journeys-cards.xlsx` - the card catalog: cards, sets, classes, adventures, journey map, bosses. This is the source of truth.
- `tts/build/` - the build: `catalog.py` (card data) and `build.py` (makes the deck sheets, images, `data.lua` and the save).
- `tts/src/global.lua` - the mod's script (hand-written). `tts/src/data.lua` is generated by the build, so don't edit it.
- `tts/sheets/`, `tts/images/` - generated images. TTS loads them from this repository.
- `tts/Journeys.json` - the TTS save ("Journeys - Playtest"). Copy it to `Documents/My Games/Tabletop Simulator/Saves`.
- `tts/README.md` - how to play with the mod.

## Building
```
python3 tts/build/build.py <repo folder> https://raw.githubusercontent.com/galvanicchoir/journeys-tts/main
```
Every image link gets `?v=<content hash>`, so a changed image always gets a new link and TTS never shows a stale cached copy.

## Encounter card frame
```
pip install playwright openpyxl pillow
python -m playwright install chromium
python3 tts/build/render_cards.py <repo folder>            # all encounter cards
python3 tts/build/render_cards.py <repo folder> TWG-004    # just these ids
```
Then run the build as above. The frame is `tts/build/card_frame/frame.css` (fonts: Cinzel and Alegreya, SIL Open Font License).
- Card data comes from the Cards sheet. The type line's role (`Goblin - Backline`) becomes the rank bar. Bracket text is no longer shown: any enemy can join any stack.
- Boss die results in rules text (`A - ...`, `B - ...`, `C - ...`) become the die symbols. Pick the set with `DIE_FAMILY` in `render_cards.py` (eyes, claws, flames or pips; drawn in `card_frame/die_icons.py`).
- An enemy with 0 power and an `Act -` ability shows a cast symbol in place of its power.
- Art: drop a file named after the card into `art/encounters/`. With none, the art is cut from the card's old export, unless that only has a placeholder silhouette; then the card shows an ART box.
- Long names and rules text shrink to fit; the script prints CHECK lines for any that still don't.
- To go back to the old export for a card, delete its file under `cards/framed/`.
